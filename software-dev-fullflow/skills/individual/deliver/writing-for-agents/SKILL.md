# Skill: writing-for-agents（写给 Agent 的文档）

写任何给 Agent 消费的文档——skill、`AGENTS.md`/`SOUL.md`、靠指针抵达的文档——包装不同，写法相同：让 Agent 每次跑出**同样的过程**，而非同样的输出。

## Context pointer（上下文指针）

**指针** = Agent 上下文里的一条引用，指向某个上下文外的材料，并编码「何时去够它」的条件。skill 的 description 是其一；`AGENTS.md` 里指向某文档的一行也是。**决定 Agent 何时够到材料的，是指针的措辞，不是目标**——必须够到的目标配一条弱措辞的指针 = 方差 bug：先锐化措辞，锐化失败才 inline。

指针干两件事：说明材料是什么 + 列出该触发它的**分支**（文档处理的每个不同情况，让不同 run 走不同路径）。常驻指针的每个字每轮都花成本，所以比正文更该剪：
- **打头词前置**（指针靠打头词触发）。
- **一个触发一个分支**（同义词重命名同一分支 = 一个分支写两遍，合并）。
- **砍掉正文已携带的身份信息**。

## 两种成本

每份文档/指针花两种预算之一：
- **Context load（上下文成本）**：常驻材料对窗口的开销——`AGENTS.md` 一行、skill description，每轮都在上下文里花 token 和注意力，无论触不触发。
- **Cognitive load（认知成本）**：人的开销——哪些文档存在、何时去够。这不是要最小化的成本，是人的主动性之代价：人的判断值钱的地方花，不值钱的地方删。

只靠指针抵达的材料，用指针一行换掉上下文成本；连指针都没有的材料，全靠认知成本扛。

## 信息层级（渐进披露）

文档由两种内容构成——**steps**（Agent 按序执行的动作）和 **reference**（按需查的定义/规则/事实）——自由混合。核心决策是每块放层级阶梯的哪一级：

1. **In-file step 文件内步骤**：主层级，Agent 要做什么、按序。
2. **In-file reference 文件内参考**：按需查，常是平铺的规则集（评审的每条规则同一级）——合法，不是坏味道。
3. **Disclosed reference 披露参考**：推到单独文件、靠指针抵达、指针触发才加载。

推得太浅顶层臃肿，推得太深藏掉了 Agent 真需要的。**渐进披露 = 沿阶梯下移**（移出主文件、藏到指针后），让顶层保持清爽。**分支是最干净的披露测试**：每个分支都要的 inline，只有部分分支要的推指针后。**共置（co-location）**是文件内伴侣：一个概念的定义/规则/坑放同一标题下，读一处带出邻座。

## Steps 与完成标准

每个 step 以一个**完成标准**收口——告诉 Agent 活干完了的条件。两个属性：
- **清晰度**：Agent 能分清「done vs not-done」吗？模糊边界（「理解达成」）招致**过早完成**。优先**锐化边界**（局部便宜）；真模糊且观察到抢跑，才通过切分序列隐藏后续步骤（只有跨真实上下文边界——交接或子代理派发——隐藏才有效）。
- **要求强度**：措辞驱动**实打实的 legwork**（「每个改动的模型都说明到」逼出彻底，「出个变更清单」不逼）。

最强的完成标准**既可检查又穷尽**。

## Leading word（打头词）

**打头词** = 一个已在模型预训练里的紧凑概念，Agent 跑文档时用来思考（_lesson_、_fog of war_、_tracer bullets_）。当 token 重复（永不整句），它累积分布式定义、用最少 token 锚定一整片行为。自造词不招募任何先验——你花定义 token 换免费的先验词，所以**先找现成词**。它锚定两次：正文里_执行_（每次出现同一行为），指针里_调用_（共享语言让它更可靠地抵达材料）。

**否定是这条的失败模式**：靠禁令引导会把被禁行为拖进上下文、让它更可用（「别想大象」= 只剩大象）。禁令半读成「去做」的指令。**提示正面**——陈述目标行为（「写一行注释」），让被禁的那个永不出口。禁令只配当无法正面表述的硬护栏，且必须配上正面目标。

## 剪枝

- **单一真相源**：每个含义一处权威定义，改行为是一处编辑。**重复**（同一含义多处）= 维护成本 + token 成本 + 抬高某含义在层级上的虚假排名。
- **环境也是真相源**：`package.json` scripts、配置文件、目录布局、`--help`。文档复述它 = 缓存，只在查找昂贵时才值。**缓存 Agent 自己找不到的**：不成文约定、选择背后的原因、配置不承认的坑。一文件一命令的查找留给环境，避免过期。
- **逐行查相关性**：不承担任务的（纯铺陈、该披露的分支）或已过时的都删。不剪枝的默认命运是**沉积**——陈旧层堆积到你要钻下去找还有效的部分。
- **逐句猎 no-op**：模型默认就服从的指令，付了成本说废话。测试标准（「是否改变默认行为」）是模型相对的，跑文档定，不靠辩论。句子没通过就整句删。测试也给打头词打分：弱到打不过默认的词（Agent 已经挺 thorough 时喊 _be thorough_）是 no-op，解法是更强的词（_relentless_），不是换技巧。

## 输出

## 安全边界
