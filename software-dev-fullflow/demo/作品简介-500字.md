# 作品简介（500 字内）

## 作品名称

软件研发全流程协同多 Agent 系统

## 正文

软件缺陷修复是一条长链路：需求聚合、根因定位、代码修改、测试验证、灰度发布、上线复盘，每一步都可能出错，经验难沉淀。本作品在阿里开源 AgentTeams 平台上，造出一支「软件研发 Agent 团队」：由固定 Leader（团队Leader）从一套完整班子（产品经理、架构师、前端、后端、修理工、测试、运维、复盘共 8 个职能）按阶段挑人参与，把链路串成 PDCA 闭环，全程留痕、可审计、可回滚。

一是闭环真正能跑。已驱动一套班子跑通完整闭环：一个"登录接口空用户名返回 500"的缺陷，从聚合、定位根因，到修复、10 个自动化测试通过、发布确认、复盘归档，181 秒走完，产出真实代码。

二是员工间真实协作。测试可向后端要开发日志、后端响应接口请求，员工用统一记忆系统沉淀各自经验；验证不靠自评，测试员用确定性脚本当裁判，补上官方框架缺失的客观质量门禁。

三是团队能学习成长。Leader 按项目需求从班子里挑人、组队、收尾归档；复盘沉淀的知识会统计被后续任务复用的次数，折算为成员"成长分"并入绩效评价，驱动团队越跑越懂项目。

作品以 AgentTeams 为唯一协同基点，覆盖官方输入、拆解、上下文传递、工具调用、结果验证、证据沉淀、审批回滚、经验沉淀 8 环节，共享状态、RAG 知识沉淀、知识复用统计、轨迹可观测均已落地。确定性调度层计划贡献回 AgentTeams 开源生态。
